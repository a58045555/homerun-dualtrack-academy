# 注音符號音檔

## 來源與授權

本資料夾的 37 個音檔取自教育部《國語注音符號手冊》（2017 數位版）的音檔，依 CC BY 4.0 授權使用：
https://language.moe.gov.tw/001/Upload/files/site_content/M0001/juyin/html_ch/index.html

修改：本站將原始錄音調整為 0.8 倍速（不變調）、將音量標準化到約 -14 LUFS（部分檔案加上輕微壓縮讓 37 個音量一致），並轉為 mp3。

網站會直接播放這些音檔；家長可在家長區選擇「優先播放家長錄音」。
