# 小小探索學院

給孩子使用的國語、注音、英文、數學、邏輯與科學學習網站，含分齡練習、多位孩子、錯題複習、手寫草稿及家長設定。純前端運作，無須安裝 npm 套件或架設資料庫。

## 本機預覽

安裝 Node.js 後，在專案目錄執行：

```sh
node preview.cjs
```

開啟 <http://127.0.0.1:8765>。預覽伺服器只接受本機連線。正式網站請使用 HTTPS，供麥克風與家長密碼功能正常運作。直接雙擊 HTML 不適合作為正式使用方式。

## 檔案結構與部署

- `index.html`：網頁入口、啟動失敗提示與相容性處理。
- `assets/app.js`：題庫、出題、畫面、語音、手寫與本機資料管理。
- `assets/styles.css`：網站樣式、手機排版與減少動態效果設定。
- `audio/`：26 個英文字母、75 個英文單字、30 個英文句子、37 個注音 MP3，以及來源說明。
- `check.cjs`：不依賴第三方套件的回歸測試。
- `VERIFICATION.md`：本次檢查紀錄與驗證限制。

部署時一起上傳 `index.html`、`assets/`、`audio/`，使用一般靜態網站主機即可；不需要建置指令。不要只上傳 HTML。音檔使用相對網址，可部署在子目錄。語音授權見 [英文說明](audio/ATTRIBUTION.txt) 與 [注音說明](audio/zhuyin/README.md)。

## 孩子與家長的使用方式

孩子選自己的卡片，再選科目、練習項目。新使用者預設手動切換下一題，讓孩子先看懂解析；既有家長明確儲存的設定會保留。開啟自動切題後，至少停留 6 秒，長解析最多停留 20 秒，孩子可按「我要慢慢看」取消該題的自動切換。答錯與深度題仍須手動繼續。

新建幼兒園大班檔案預設每回合 5 題；家長可調整為 5、8、10 題。家長區包含難度、朗讀、孩子管理與資料備份。

## 進度與備份

每位孩子的已完成回合、錯題與心得分開保存在瀏覽器 localStorage，家長錄音存在 IndexedDB。沒有跨裝置同步；更換網站網域、瀏覽器或清除網站資料，都可能使原紀錄無法讀取。請由家長定期匯出每位孩子的 JSON 備份。錄音與家長密碼不在 JSON 備份中。

成功更新紀錄前，網站會保留上一份不同的原始資料；在「家長區 → 資料密碼」可匯出目前紀錄、原始儲存資料與上一份自動備份。上一份備份也是本機資料，不能取代下載到裝置的備份。

若原始紀錄損壞，網站暫停覆寫，並顯示持續提示；請先匯出原始資料，再以有效備份匯入。匯入確認會顯示目前孩子與備份來源，避免混入別人的紀錄。若儲存空間不足，網站顯示未儲存提示，仍可匯出畫面中保留的資料。未完成回合與手寫草稿會保存在原孩子的本機紀錄；重新開啟後，由首頁按「接著做」或「繼續手寫」。題目、已作答回饋和筆跡會保留，恢復時不自動播放或跳題。換裝置、清除瀏覽器資料或教材版本／年級不符時無法續作。開始新回合前會提醒是否取代未完成回合。

## 驗證

```sh
node check.cjs
node check-resume.cjs
```

測試涵蓋五科四級各題型的題目結構、四個選項唯一性、答案存在、獨立算術核對、完整回合保存、防重複計分、切題計時、讀題取消、資料損壞／空間不足處理、孩子隔離、音檔完整性與語音失敗降級。測試在隔離的模擬環境運作，不會讀寫使用者的真實瀏覽器資料。

預覽伺服器啟動後，可另執行 `node check-http.cjs` 檢查網頁及全部音檔的 HTTP 回應與內容長度。
